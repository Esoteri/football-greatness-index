# Football Greatness Index (FGI)

## Overview

The Football Greatness Index (FGI) is a long-term Python, SQL, and sports analytics project designed to evaluate and compare footballers across historical eras, playing positions, clubs, national teams, and competitions.

## Project Status

**Current Phase:** Milestone 0 — Project Foundation

The project is currently in its initial planning and architecture stage.

## Objectives

- Develop a historical football database.
- Create a transparent greatness evaluation methodology.
- Compare footballers across positions and eras.
- Produce reproducible rankings and analytical reports.
- Develop practical software engineering and data science skills.

## Technology Stack

- Python
- SQL / SQLite
- VS Code
- Git / GitHub
- Future: pandas, PostgreSQL, Jupyter, and web technologies

## Directory Structure

- `data/` — Football datasets
- `database/` — Database definitions
- `docs/` — Planning and technical documentation
- `notebooks/` — Analytical research notebooks
- `outputs/` — Rankings, reports, and visualizations
- `src/` — Python source code
- `tests/` — Automated tests
